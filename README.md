📂 automatizacoes-varias
Repositório de utilitários em Python para automatizar tarefas administrativas repetitivas e o processamento de ficheiros.

🚀 O que faz?
Converte folhas Excel complexas (múltiplas abas, 4 a 10 colunas) em:

Relatório HTML Consolidado: Agrega todas as abas num único ficheiro.

Documentos Word Individuais (.docx): Gera um ficheiro por aba com formatação autónoma.

🎨 Padrões de Design & Tratamento
Datas Literais: Preservação estrita do formato original (ex: nov/24) sem conversões automáticas.

Alinhamento Dinâmico: Automático com base nos cabeçalhos (IDs/datas ao centro, valores à direita, texto à esquerda).

Identidade Visual:

Cabeçalho: Azul institucional (#1A365D) com texto branco.

Zebra Striping: Linhas pares em #E2E8F0.

Bordas: Linhas finas (#CBD5E1). Tipografia Helvetica.

Fundo HTML: Deixado por definir (transparente fora da tabela).

🛠️ Tecnologias
Python | Pandas | Openpyxl | Python-Docx
